# MUSICALINUS 프로젝트 소개 페이지

「찬란하게 빛나는 우리들의 중3 에세이」 수업 소개 웹사이트입니다.
별도 설치나 빌드 없이 index.html을 열어 볼 수 있습니다.

## GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 **안의 파일과 assets 폴더**를 저장소 최상위에 업로드합니다. index.html이 최상위에 있어야 합니다.
3. 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch는 main, 폴더는 / (root)를 선택하고 Save를 누릅니다.
5. 배포가 끝나면 Pages 설정에 표시되는 주소에서 확인합니다.

## 파일 구성
- index.html: 소개 문구와 페이지 구조
- style.css: 화면 디자인, 모바일 대응
- app.js: 여섯 막 선택 기능 (방향키, Home, End 지원)
- assets/: 제공받은 대본 뼈대 및 체크리스트 원본 PDF/Word
- .nojekyll: 정적 파일 제공 설정

## 수정하기
학교명과 안내 문구는 index.html에서, 여섯 막의 상세 내용은 app.js의 acts에서 수정하세요.
색상은 style.css 첫 줄의 변수를 바꾸면 됩니다.
모든 파일은 UTF-8로 저장하세요. 자료 교체 시 assets의 파일명을 유지하면 링크가 그대로 작동합니다.

## 범위와 자료 기준
제공된 대본 뼈대 및 모둠별 체크리스트를 바탕으로 구성했습니다. 수업 일정은 체크리스트의 7차시를 기준으로 했습니다.
첨부된 musicalinus-main 프로젝트는 학생 로그인과 교사 관리 기능이 있는 별도 제작 플랫폼입니다. 이 패키지는 그 프로젝트를 설명하는 독립적인 소개 사이트이며, 플랫폼 서버에 연결하거나 학생 정보를 수집하지 않습니다.
원본 수업 플랫폼의 로그인 설정이나 서버 주소는 포함하지 않았습니다. 이 사이트에는 로그인·제출·녹음 기능이 없습니다.
학교 수업 자료의 공개 범위와 사용 권한은 저장소 공개 전 확인해 주세요. 라이선스는 임의로 부여하지 않았습니다.
